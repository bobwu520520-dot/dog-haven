#### 2. 传说稀有变体（双重天赋 + 专属发光毛色）

- **晴天金毛** (`variant_sunny_golden`)：
  - 基础犬种：金毛（继承原有「汤品售价 +5%」）；
  - **第二重天赋**：全体料理售价 +6%（`all_dish_price`）；
  - **发光专属配色**：晴天流光（`glow: #FFD86B`），抽中即可在衣橱为金毛穿戴，场景实时泛出日光金色辉光。
- **雪原哈士奇** (`variant_snow_husky`)：
  - 基础犬种：哈士奇（继承原有「烹饪暴击率 +5%」）；
  - **第二重天赋**：全镇自动收取速度 +20%（`auto_collect_speed`）；
  - **发光专属配色**：雪原流光（`glow: #85C1E9`），冰蓝粒子环绕。
- 变体**仅能通过钻石召唤抽取**获得，不可用金币直接招募，确立了抽卡系统的核心追求。

#### 3. 抽卡与三重保底机制 (`js/gacha.js`)

- **定价体系**：单抽 💎60 钻石，十连抽 💎540 钻石（享 9 折优惠）；
- **三重独立保底水位**：
  - **稀有保底**：连续 10 抽内必出稀有或以上；
  - **史诗保底**：连续 30 抽内必出史诗或以上；
  - **传说保底**：连续 80 抽内必出传说变体；
  - 触发高阶保底时重置全部对应及低阶计数器；
- **重复抽卡返还**：抽到已拥有犬种卡或变体时，根据稀有度全额返还钻石（普通 💎6 / 稀有 💎11 / 史诗 💎20 / 传说 💎50），避免抽卡挫败感。

### 2.2 烹饪 / 生产设施

- **5 大料理工位配置**：
  1. `stew` 鲜美炖汤锅（初始）：大骨蔬菜浓汤 → 胡萝卜鲜鸡煲 → 滋补牛腩鲜菇汤
  2. `bbq` 慢烤烧烤架（🪙150 解锁）：炭火慢烤肉串 → 脆香鸡肉卷 → 炙烤无骨纯牛排
  3. `bake` 甜品烘焙屋（🪙1,500 解锁）：萌爪骨头曲奇 → 羊奶纸杯蛋糕 → 草莓肉松舒芙蕾
  4. `hotpot` 狗狗火锅台（🪙12,000 解锁）：原汁暖心小火锅 → 鲜肉什锦杂烩锅 → 极鲜全羊寿喜煲
  5. `jerky` 肉干风干窖（🪙80,000 解锁）：手工风干鸡肉干 → 深海三文鱼脆皮 → 黄金风干牛肋骨
- **双重多线程成长曲线**：
  - **设施产出速度升级**：工位等级升 1 级提升 4% 产速，升至 Lv.20 解锁全自动出餐与自动收取；
  - **菜系食谱研发升级**：5 菜系各自具备 1~10 级食谱，每升 1 级单价提升 +8%，满级激活 +10% 全局生产提速；
  - 设施等级与食谱加成乘法叠加，形成「先升速度、后提单价」的平滑成长节奏。
